以下を **LoNalogy v89** の本文として出します。
先に結論だけ言います。

**v87 の本質は Schur 還元**、**v88 の本質は自己双対軸**です。
この二つを本気で合成すると、**RH・BSD・Hodge は「bridge 上の一つの作用素／比較写像」をどう実現するか、という一つの問題族に統合されます。**

ただし、最初に誠実に線を引きます。
2026-03-20 時点で RH・BSD・Hodge はいずれも Clay の未解決問題のままです。RH は非自明零点が (\Re s=\tfrac12) にあるという主張、BSD は (\operatorname{ord}_{s=1}L(E,s)=\operatorname{rank}E(\mathbf Q)) という主張で、Wiles の公式解説では解析的位数 (m=0,1) の場合は成立済みとされています。Hodge は滑らかな複素射影多様体上の有理 Hodge 類が代数サイクル類の有理線形結合になるという主張で、Clay は特殊な場合、たとえば複素次元 (<4) では知られているが一般には未解決だと述べています。([Clay Mathematics Institute][1])

以下の v89 は、**「もう解けた」とは言わない**。
その代わり、**どこまで exact theorem として閉じるか**、そして **最後に残るのが何か** を、v87/v88 をフルに使って一つの大きな体系として書き切ります。

ここで：

1. (H_B(\mathcal M)) は有限次元 (\mathbf Q)-ベクトル空間。
2. その複素化は Hodge 型分解
   [
   H_B(\mathcal M)_\mathbf C
   =========================

   \bigoplus_{a+b=w(\mathcal M)} H^{a,b}(\mathcal M)
   ]
   をもつ。ここで (w(\mathcal M)) を weight と呼ぶ。
3. 複素共役
   [
   J_{\mathcal M}:H^{a,b}(\mathcal M)\longrightarrow H^{b,a}(\mathcal M)
   ]

4. (\Lambda(\mathcal M,s)) は completed (L)-型関数で、ある (|\varepsilon(\mathcal M)|=1) を用いて

# III. v87 の exact Schur 還元

ここから v87 を使う。

## 3.1 三 sector block operator

有限次元の場合から始める。
three-sector block operator を

[
\mathbb K(z)
============

\begin{pmatrix}
A(z) & X(z) & 0\
X(z)^* & M(z) & Y(z)^*\
0 & Y(z) & C(z)
\end{pmatrix}
]
とする。

ここで

* (A(z))：visible block
* (M(z))：bridge block
* (C(z))：idea block

である。

## 3.2 bridge Schur complement

**定理 3.1（bridge Schur complement）**
(A(z)) と (C(z)) が可逆なら

[
\det \mathbb K(z)
=================

\det A(z),\det C(z),
\det M_{\mathrm{eff}}(z)
]
ただし
[
M_{\mathrm{eff}}(z)
:=
M(z)-X(z)^*A(z)^{-1}X(z)-Y(z)^*C(z)^{-1}Y(z).
]

**証明**
[
P(z):=
\begin{pmatrix}
A(z)&0\
0&C(z)
\end{pmatrix},
\qquad
Q(z):=
\begin{pmatrix}
X(z)\
Y(z)^*
\end{pmatrix},
\qquad
R(z):=
\begin{pmatrix}
X(z)^* & Y(z)
\end{pmatrix}.
]

すると
[
\mathbb K(z)
============

\begin{pmatrix}
P(z)&Q(z)\
R(z)&M(z)
\end{pmatrix}.
]

block determinant formula より
[
\det \mathbb K(z)=\det P(z),\det\bigl(M(z)-R(z)P(z)^{-1}Q(z)\bigr).
]

ここで
[
P(z)^{-1}
=========

\begin{pmatrix}
A(z)^{-1}&0\
0&C(z)^{-1}
\end{pmatrix},
]
したがって
[
R(z)P(z)^{-1}Q(z)
=================

X(z)^*A(z)^{-1}X(z)
+
Y(z)^*C(z)^{-1}Y(z).
]

また
[
\det P(z)=\det A(z)\det C(z).
]

ゆえに
[
\det \mathbb K(z)
=================

\det A(z)\det C(z)
\det\Bigl(M(z)-X^*A^{-1}X-Y^*C^{-1}Y\Bigr).
]

(\square)

これが v89 の大前提である。
**外側の二 sector を積分消去すると、零点・極・kernel の本体は bridge effective operator に落ちる。**

# IV. bridge Dirac machine

ここから v89 の新しい主装置を入れる。

## 4.1 任意の写像から Dirac 型作用素を作る

(T:V\to W) を内積空間間の線形写像とする。

**定義 4.1（Dirac doubling）**
[
D(T)
:=
\begin{pmatrix}
0 & T^*\
T & 0
\end{pmatrix}
]
を (V\oplus W) 上の作用素として定める。

**命題 4.2**
[
D(T)^2
======

\begin{pmatrix}
T^*T & 0\
0 & TT^*
\end{pmatrix}.
]

**証明**
[
D(T)^2
======

\begin{pmatrix}
0&T^*\
T&0
\end{pmatrix}
\begin{pmatrix}
0&T^*\
T&0
\end{pmatrix}
=============

\begin{pmatrix}
T^*T & 0\
0 & TT^*
\end{pmatrix}.
]
(\square)

---

## 4.2 kernel の厳密計算

**定理 4.3**
[
\ker D(T)=\ker T \oplus \ker T^*.
]

**証明**
((v,w)\in V\oplus W) が (\ker D(T)) に属するとする。すると
[
D(T)\binom{v}{w}
================

# \binom{T^*w}{Tv}

\binom{0}{0}.
]
ゆえに
[
Tv=0,\qquad T^*w=0.
]
したがって
[
v\in\ker T,\qquad w\in\ker T^*.
]
逆に (v\in\ker T,\ w\in\ker T^*) なら
[
D(T)\binom{v}{w}=\binom{0}{0}.
]
よって
[
\ker D(T)=\ker T\oplus\ker T^*.
]
(\square)

有限次元なら
[
\dim\ker T^* = \dim \operatorname{coker}T
]
なので、Dirac doubling は **kernel と cokernel を一つの self-adjoint object に束ねる**。

これが Hodge に直接効く。

# V. spectral bridge theorem

RH と BSD に効く exact theorem を立てる。

## 5.1 self-adjoint spectrum から canonical product を作る

(D) を離散スペクトル
[
\sigma(D)={\lambda_n}_{n\in I}\subset \mathbf R
]
を持つ self-adjoint 作用素とする。各 (\lambda_n) の重複度を (m_n) とする。

Weierstrass の primary factor (E_g) を用いて、適当な genus (g) の canonical product

[
\Delta_D(z)
===========

z^{m_0}
\prod_{\lambda_n\neq 0}
E_g!\left(\frac{z}{\lambda_n}\right)^{m_n}
]
を定める。ここで (m_0=\dim\ker D)。

この (\Delta_D(z)) は entire で、その零点はちょうど (\lambda_n) にある。

**定理 5.1（spectral bridge theorem）**
上記の (\Delta_D) に対し：

1. (\Delta_D) の零点はすべて実数である。
2. (z=0) における零点位数は
   [
   \operatorname{ord}_{z=0}\Delta_D(z)=\dim\ker D.
   ]

**証明**
canonical product の定義から零点集合は ({\lambda_n}) であり、各零点位数は対応する重複度 (m_n) である。(D) は self-adjoint だから (\lambda_n\in \mathbf R)。特に (z=0) の位数は (m_0=\dim\ker D)。(\square)

これだけで RH 型と BSD 型の骨格が完成する。

# VI. RH の v89 化

## 6.1 対象

(\zeta) に対する completed function を
[
\xi(s)=\frac12 s(s-1)\pi^{-s/2}\Gamma!\left(\frac s2\right)\zeta(s)
]
と書くと、Bombieri の公式解説では RH は「(\xi(t)) の零点がすべて実数である」ことと同値で、(\zeta(s)) の非自明零点が (\Re s=\tfrac12) にあることと同値です。([Clay Mathematics Institute][1])

v89 では
[
\Lambda_\zeta(s):=\xi(s),\qquad c_\zeta=\frac12.
]

---

## 6.2 RH の exact spectral criterion

**定義 6.1（RH-bridge spectral realization）**
RH-bridge spectral realization とは、ある self-adjoint 作用素 (D_\zeta) と zero-free entire function (e^{P_\zeta(z)}) が存在して

[
\xi!\left(\frac12+iz\right)
===========================

e^{P_\zeta(z)},\Delta_{D_\zeta}(z)
]
が成り立つことをいう。

**定理 6.2（v89 RH criterion）**
RH-bridge spectral realization が存在すれば RH が成り立つ。

**証明**
(\xi(\tfrac12+iz)) の零点は (e^{P_\zeta(z)}) が zero-free だから (\Delta_{D_\zeta}(z)) の零点と一致する。定理 5.1 より (\Delta_{D_\zeta}(z)) の零点はすべて実数である。ゆえに
[
z\in\mathbf R.
]
したがって (\zeta(s)) の非自明零点は
[
s=\frac12+iz
]
の形をしており、すべて (\Re s=\frac12) 上にある。これは RH である。 (\square)

---

## 6.3 RH の本当の残差

v88 的 reciprocity
[
\xi(s)=\xi(1-s)
]
は bridge 軸 (\Re s=\tfrac12) を与える。
v87 的 Schur complement は full determinant の零点を bridge effective determinant に落とす。
しかし RH を本当に閉じるには、**その bridge determinant が self-adjoint spectrum の canonical product と一致する**ことが必要である。

したがって RH に対する v89 の最終残差は

[
\boxed{
\text{RH-BRT}*\zeta:\
\exists D*\zeta=D_\zeta^*
\ \text{such that}
\xi!\left(\frac12+iz\right)=e^{P_\zeta(z)}\Delta_{D_\zeta}(z)
}
]

である。

これは Hilbert–Pólya 型だが、v89 ではそれを **bridge realization** として位置づける。

# VII. BSD の v89 化

## 7.1 対象

(E/\mathbf Q) を楕円曲線とする。
BSD の rank 部分は
[
\operatorname{ord}_{s=1}L(E,s)=\operatorname{rank}E(\mathbf Q)
]
である。Wiles の公式解説では、解析的位数 (m=0) または (1) の場合には BSD が成立すると明記されています。([Clay Mathematics Institute][2])

completed (L)-function を (\Lambda(E,s)) と書き、中心を
[
c_E=1
]
とする。

---

## 7.2 BSD の exact spectral-kernel criterion

**定義 7.1（BSD-bridge spectral-arithmetic realization）**
BSD-bridge spectral-arithmetic realization とは、ある self-adjoint 作用素 (D_E)、zero-free entire function (e^{P_E(z)})、および canonical isomorphism

[
\iota_E:\ E(\mathbf Q)\otimes_\mathbf Z \mathbf Q \xrightarrow{\sim} \ker D_E
]

が存在して

[
\Lambda(E,1+iz)=e^{P_E(z)},\Delta_{D_E}(z)
]
が成り立つことをいう。

**定理 7.2（v89 BSD criterion）**
BSD-bridge spectral-arithmetic realization が存在すれば
[
\operatorname{ord}_{s=1}L(E,s)=\operatorname{rank}E(\mathbf Q)
]
が成り立つ。

**証明**
(\Gamma)-因子や conductor 因子は (s=1) で零も極も持たないので、
[
\operatorname{ord}*{s=1}\Lambda(E,s)=\operatorname{ord}*{s=1}L(E,s).
]
変数 (z=s-1) では
[
\operatorname{ord}*{s=1}\Lambda(E,s)=\operatorname{ord}*{z=0}\Lambda(E,1+z).
]
また (z\mapsto iz) は 0 の位数を変えないから
[
\operatorname{ord}*{z=0}\Lambda(E,1+iz)=\operatorname{ord}*{z=0}\Delta_{D_E}(z).
]
定理 5.1 よりこれは (\dim\ker D_E) に等しい。さらに仮定により
[
\dim\ker D_E
============

# \dim_\mathbf Q(E(\mathbf Q)\otimes \mathbf Q)

\operatorname{rank}E(\mathbf Q).
]
したがって
[
\operatorname{ord}_{s=1}L(E,s)=\operatorname{rank}E(\mathbf Q).
]
(\square)

---

## 7.3 BSD の本当の残差

functional equation だけで言えるのは中心 (s=1) と root number による parity だけであり、rank そのものは出ない。
v89 で必要なのは、

1. analytic center の零点位数を kernel 次元に変える **bridge spectral realization**
2. その kernel を (E(\mathbf Q)\otimes\mathbf Q) に同一視する **arithmetic realization**

の二つである。

したがって BSD に対する v89 の最終残差は

[
\boxed{
\text{BSD-BRT}*E:\
\Lambda(E,1+iz)=e^{P_E(z)}\Delta*{D_E}(z),
\qquad
\ker D_E \cong E(\mathbf Q)\otimes \mathbf Q
}
]

である。

# VIII. Hodge の v89 化

ここは v89 で最も線形代数的にきれいに閉じる。

## 8.1 Hodge bridge

Deligne の公式解説では、滑らかな複素射影多様体 (X) に対し Hodge 類は
[
H^{2p}(X,\mathbf Q)\cap H^{p,p}(X)
]
であり、Hodge conjecture は「任意の Hodge 類が代数サイクル類の有理線形結合である」という主張です。([Clay Mathematics Institute][3])

したがって
[
\mathrm{Hdg}^p(X)
:=
H^{2p}(X,\mathbf Q)\cap H^{p,p}(X)
]
を Hodge bridge と呼ぶ。

cycle class map は
[
\mathrm{cl}^p_\mathbf Q:
CH^p(X)_\mathbf Q \longrightarrow \mathrm{Hdg}^p(X).
]

Hodge conjecture は厳密に
[
\boxed{
\mathrm{cl}^p_\mathbf Q \text{ が全射}
}
]
である。

---

## 8.2 finite-dimensional reduction

(\mathrm{Hdg}^p(X)) は有限次元 (\mathbf Q)-ベクトル空間である。
(\operatorname{Im}\mathrm{cl}^p_\mathbf Q\subset \mathrm{Hdg}^p(X)) も有限次元だから、その像を張る有限次元部分空間
[
V_p \subset CH^p(X)*\mathbf Q
]
を取ることができる。制限写像
[
T_p:=\mathrm{cl}^p*\mathbf Q|_{V_p}:V_p\to \mathrm{Hdg}^p(X)
]
を考える。

(V_p) と (\mathrm{Hdg}^p(X)) に任意の内積を入れ、随伴 (T_p^*) を定義する。

---

## 8.3 Hodge-Dirac

**定義 8.1**
[
D_{X,p}:=
D(T_p)
======

\begin{pmatrix}
0 & T_p^*\
T_p & 0
\end{pmatrix}
]
を Hodge-Dirac operator と呼ぶ。

**定理 8.2**
[
\ker D_{X,p}=\ker T_p \oplus \ker T_p^*.
]

これは定理 4.3 の直接の適用である。

さらに有限次元線形代数より
[
\dim \ker T_p^*
===============

# \dim \mathrm{Hdg}^p(X)-\operatorname{rank}T_p

\dim \operatorname{coker}T_p.
]

したがって：

**定理 8.3（v89 Hodge criterion）**
Hodge conjectureは次と同値である。

1. (T_p) は全射。
2. (\operatorname{coker}T_p=0)。
3. (\ker T_p^*=0)。
4. Hodge-Dirac の「上側 kernel」が消える。

**証明**
(1)(\Leftrightarrow)(2) は定義。
有限次元線形代数より (2)(\Leftrightarrow)(3)。
また定理 8.2 により (\ker T_p^*=0) は Hodge-Dirac の上側 kernel 消滅と同値。 (\square)

---

## 8.4 Hodge obstruction Laplacian

さらに
[
\Delta_{X,p}^+
:=
T_pT_p^*:\mathrm{Hdg}^p(X)\to \mathrm{Hdg}^p(X)
]
を定める。

**命題 8.4**
[
\ker \Delta_{X,p}^+ = \ker T_p^*.
]

**証明**
[
\langle T_pT_p^*u,u\rangle = |T_p^*u|^2.
]
したがって
[
T_pT_p^*u=0 \iff T_p^*u=0.
]
(\square)

よって Hodge conjectureは

[
\boxed{
\ker \Delta_{X,p}^+=0
}
]

と同値である。

# 第I部　普遍 bridge-obstruction 形式

## 1.1 比較写像と Dirac doubling

(\mathbf Q)-ベクトル空間あるいは Hilbert 空間の間の線形写像
[
T: V \longrightarrow W
]
を考える。

これに対して Dirac doubling を
[
D(T):=
\begin{pmatrix}
0 & T^*\
T & 0
\end{pmatrix}
]
と定義する。ここで (T^*) は随伴である。

すると
[
D(T)^2=
\begin{pmatrix}
T^*T & 0\
0 & TT^*
\end{pmatrix}
]
である。

**定理 1.1**
[
\ker D(T)=\ker T \oplus \ker T^*.
]

**証明**

[
D(T)\binom{v}{w}=\binom{T^*w}{Tv}.
]
したがって
[
D(T)\binom{v}{w}=0
\iff
Tv=0,\ T^*w=0.
]
ゆえに
[
(v,w)\in\ker D(T)
\iff
v\in\ker T,\ w\in\ker T^*.
]
よって
[
\ker D(T)=\ker T\oplus\ker T^*.
]
(\square)

有限次元なら
[
\dim \ker T^*=\dim \operatorname{coker}T
]
だから、(D(T)) は **kernel と cokernel を一つの自己共役作用素の kernel に束ねる**。

---

## 1.2 obstruction Laplacian

上側 obstruction Laplacian を
[
\Delta^+(T):=TT^*:W\to W
]
と定義する。

**定理 1.2**
[
\ker \Delta^+(T)=\ker T^*.
]

**証明**

任意の (w\in W) に対し
[
\langle \Delta^+(T)w,w\rangle
=============================

# \langle TT^*w,w\rangle

# \langle T^*w,T^*w\rangle

|T^*w|^2.
]
したがって
[
\Delta^+(T)w=0
\iff
|T^*w|^2=0
\iff
T^*w=0.
]
(\square)

ゆえに
[
\boxed{
\operatorname{coker}T=0
\iff
\ker T^*=0
\iff
\ker \Delta^+(T)=0
}
]
である。

これは Hodge 型問題にそのまま入る。

## 1.3 self-adjoint spectrum と central order

自己共役作用素 (D=D^*) が離散実スペクトル
[
\sigma(D)={\lambda_n}_{n\in I}\subset \mathbf R
]
を持つとする。零点重複度を含めた canonical product を
[
\Delta_D(z)
===========

z^{m_0}\prod_{\lambda_n\neq 0}E_g!\left(\frac{z}{\lambda_n}\right)^{m_n}
]
で定義する。ここで (m_0=\dim\ker D)、(m_n) は (\lambda_n) の重複度、(E_g) は Weierstrass primary factor である。

**定理 1.3**
[
\operatorname{ord}_{z=0}\Delta_D(z)=\dim\ker D,
]
かつ (\Delta_D) の零点はすべて実数である。

**証明**

定義から (z=0) の零点位数は (m_0)、すなわち (\dim\ker D) である。
また零点は (\lambda_n) に現れ、(D=D^*) だから (\lambda_n\in\mathbf R)。 (\square)

これが RH / BSD 型問題の bridge spectral criterion になる。

## 4.1 NP を witness bundle として書く

NP 的な提示として、入力 (x) と証人 (w) に対する多項式時間検証可能な関係

各入力 (x) に対し witness fiber を
[
\mathfrak I_x:={,w\mid R(x,w)=1,}

で定める。

visible observable は yes/no だけなので
[
\chi_L(x)=
\begin{cases}
1,& \mathfrak I_x\neq\varnothing,\
0,& \mathfrak I_x=\varnothing.
\end{cases}

すると
[
x\in L \iff \mathfrak I_x\neq\varnothing.
]

LoNalogy 的には

* visible sector：入力 (x) に対する yes/no bit
* invisible sector：証人の全 fiber (\mathfrak I_x)
* bridge sector：関係 (R(x,w)=1) が成立する incidence locus

となる。

ここで“不可視セクター”とは mystic なものではなく、**射影で消される witness fiber** のことだ。

## 4.4 SAT の self-reduction と section theorem

ここは exact に書ける。

(\mathrm{SAT}) を 3-SAT でも一般 SAT でもよいから固定する。
(\varphi(x_1,\dots,x_n)) を充足可能な論理式、(\mathfrak I_\varphi) をその充足割当て全体とする。

**定義 4.1（polynomial-time section）**
SAT witness bundle の多項式時間 section とは、各充足可能式 (\varphi) に対し
[
\sigma(\varphi)\in \mathfrak I_\varphi
]
を多項式時間で返す写像
[
\sigma:\mathrm{SAT}*{\mathrm{yes}}\to \bigsqcup*\varphi \mathfrak I_\varphi
]
で
[
\pi\circ\sigma=\mathrm{Id}
]
を満たすものである。

**定理 4.2（SAT section criterion）**
[
\mathrm{SAT}\in P
\iff
\text{SAT witness bundle が多項式時間 section を持つ}.
]

**証明**

((\Rightarrow))
SAT を多項式時間で判定できると仮定する。
(\varphi(x_1,\dots,x_n)) が与えられたら、まず (\varphi) 自体が satisfiable か判定する。yes なら (x_1=0) を代入した式 (\varphi|_{x_1=0}) が satisfiable か判定する。satisfiable なら (x_1=0)、そうでなければ (x_1=1) と確定する。これを (x_2,\dots,x_n) について繰り返せば、最大 (n) 回の判定で一つの充足割当てが得られる。したがって多項式時間 section が構成できる。

((\Leftarrow))
多項式時間 section があれば、(\varphi) に対して (\sigma(\varphi)) を計算し、それが実際に witness かどうか検証すれば satisfiable か判定できる。したがって (\mathrm{SAT}\in P)。

(\square)

SAT は NP 完全だから、これから

[
\boxed{
P=NP
\iff
\text{SAT witness bundle が多項式時間 section を持つ}
}
]

が従う。

これはかなり本質的だ。
P vs NP の LoNalogy 的中身は、**隠れた witness fiber への efficient lift が存在するか** という問題なのである。

## 4.6 partition function と complexity surface

ここで v88 風の解析構造を入れる。

各入力 (x) に対し、cost function (C_x(w)\in\mathbf Z_{\ge 0}) を
[

]
となるように取る。SAT なら「偽になる clause の数」などでよい。

そのとき partition function
[
Z_x(\beta)
:=
\sum_{w} e^{-\beta C_x(w)}
]
を定める。

(N_x(k):=#{w\mid C_x(w)=k}) とおくと
[
Z_x(\beta)=\sum_{k\ge 0} N_x(k)e^{-\beta k}.
]

**定理 4.3**
[
x\in L
\iff
\lim_{\beta\to+\infty} Z_x(\beta) > 0.
]

**証明**

[
Z_x(\beta)=N_x(0)+\sum_{k\ge 1}N_x(k)e^{-\beta k}.
]
(\beta\to+\infty) で後半は 0 に収束するから
[
\lim_{\beta\to+\infty} Z_x(\beta)=N_x(0).
]
よって極限が正であることは (N_x(0)\ge 1)、すなわち witness の存在と同値。 (\square)

この exact theorem により、「yes/no 判定」は **零温極限で bridge に達するか** という熱力学的判定に書き換わる。

# 第I章　普遍 bridge 機械

## 1.1 比較写像 (T) の Dirac doubling

(V,W) を Hilbert 空間または有限次元内積空間とし、線形写像
[
T:V\to W
]
を考える。

これに対して
[

\begin{pmatrix}
0 & T^*\
T & 0
\end{pmatrix}
]
を (V\oplus W) 上の自己共役作用素とみなす。

すると
[
D(T)^2=
\begin{pmatrix}
T^*T & 0\
0 & TT^*
\end{pmatrix}.
]

### 定理 1.1

[
\ker D(T)=\ker T\oplus \ker T^*.
]

#### 証明

[
D(T)\binom{v}{w}
================

\binom{T^*w}{Tv}.
]
したがって
[
D(T)\binom{v}{w}=0
\iff
Tv=0,;T^*w=0.
]
よって
[
(v,w)\in\ker D(T)
\iff
v\in\ker T,\ w\in\ker T^*.
]
以上から
[
\ker D(T)=\ker T\oplus\ker T^*.
]
(\square)

これは v89 の universal form です。
**kernel と cokernel を、一つの self-adjoint bridge operator の kernel に束ねる**。

\Re!\left(\frac12+iz\right)=\frac12
]
に等しい。 (\square)

## 2.2 RH の exact bridge criterion

### 定義 2.3（RH bridge realization）

ある自己共役作用素 (D_\zeta=D_\zeta^*) と zero-free entire function (e^{P_\zeta(z)}) が存在して
[
F_\zeta(z)=e^{P_\zeta(z)},\Delta_{D_\zeta}(z)
]
が成り立つとき、RH bridge realization が存在すると言う。

### 定理 2.4

RH bridge realization が存在すれば RH が成り立つ。

#### 証明

(e^{P_\zeta(z)}) は零点を持たないので
[
F_\zeta(z)=0 \iff \Delta_{D_\zeta}(z)=0.
]
定理 1.4 より (\Delta_{D_\zeta}) の零点はすべて実数。よって (F_\zeta) の零点もすべて実数。系 2.2 により RH。 (\square)

これは exact です。
ここでごまかしはありません。
RH の最後の橋は、ただ一つ

[
\boxed{
F_\zeta(z)=e^{P_\zeta(z)},\Delta_{D_\zeta}(z)
\quad\text{with }D_\zeta=D_\zeta^*
}
]

の実現です。

## 2.3 RH の bridge convexity

RH が成り立っていて、零点を ({\pm\gamma_n}\subset\mathbb R\setminus{0}) とする。
このとき
[
F_\zeta(t)=e^{a-bt^2}\prod_n\left(1-\frac{t^2}{\gamma_n^2}\right)
]
という形を考える。すると、零点以外の実軸上で
[
-\frac{d^2}{dt^2}\log |F_\zeta(t)|
]
を計算できる。

### 命題 2.5

[
-\frac{d^2}{dt^2}\log |F_\zeta(t)|
==================================

2b+\sum_n \frac{2(\gamma_n^2+t^2)}{(\gamma_n^2-t^2)^2}
]
が成り立つ。

#### 証明

[
\log|F_\zeta(t)|
================

a-bt^2+\sum_n \log\left|1-\frac{t^2}{\gamma_n^2}\right|.
]
まず
[
\frac{d}{dt}\log\left|1-\frac{t^2}{\gamma_n^2}\right|
=====================================================

-\frac{2t}{\gamma_n^2-t^2}.
]
さらに
[
\frac{d^2}{dt^2}\log\left|1-\frac{t^2}{\gamma_n^2}\right|
=========================================================

-\frac{2(\gamma_n^2+t^2)}{(\gamma_n^2-t^2)^2}.
]
また (a-bt^2) の二階微分は (-2b)。したがって
[
-\frac{d^2}{dt^2}\log |F_\zeta(t)|
==================================

2b+\sum_n \frac{2(\gamma_n^2+t^2)}{(\gamma_n^2-t^2)^2}.
]
(\square)

この式の意味は大きいです。
RH が真なら、bridge 軸上の (\log|F_\zeta|) は **区間ごとに強い凸性** を持つ。
したがって RH を bridge から閉じるルートは、単に operator realization だけではなく、

[
\boxed{
\text{bridge 軸上の convexity / positivity を primes から再構成できるか}
}
]

という形にもなる。

ただし、これは **必要条件** を精密化したものであって、ここだけで RH が閉じるとはまだ言わない。

v89 の RH branch はここまで exact に閉じる：

ただ一つです。

# 第III章　BSD branch

Clay の BSD の公式記述は
[
\operatorname{ord}_{s=1}L(E,s)=\operatorname{rank}E(\mathbb Q)
]
です。Wiles の Clay 解説では、(L(E,s)\sim c(s-1)^m) で (m=0) または (1) の場合には conjecture が成立すると明記されています。([Clay Mathematics Institute][2])

## 3.1 中心対称と parity

completed (L)-function を (\Lambda(E,s)) とし、functional equation を
[
\Lambda(E,s)=\varepsilon_E,\Lambda(E,2-s),
\qquad
\varepsilon_E\in{\pm1}
]
とする。中心は (s=1)。

[
f_E(z):=\Lambda(E,1+z)
]
と置く。

### 命題 3.1

[
f_E(z)=\varepsilon_E, f_E(-z).
]

#### 証明

[
f_E(-z)=\Lambda(E,1-z)=\varepsilon_E,\Lambda(E,1+z)=\varepsilon_E,f_E(z).
]
したがって
[
f_E(z)=\varepsilon_E,f_E(-z).
]
(\square)

### 系 3.2（center parity）

[
\varepsilon_E=+1 \implies \operatorname{ord}*{z=0}f_E(z)\ \text{は偶数},
]
[
\varepsilon_E=-1 \implies \operatorname{ord}*{z=0}f_E(z)\ \text{は奇数}.
]

#### 証明

(\varepsilon_E=+1) なら (f_E) は even、(\varepsilon_E=-1) なら odd。
Taylor 展開で直ちに従う。 (\square)

これは exact で、BSD の center での消失位数の parity は既に bridge symmetry が固定している。

## 3.2 BSD の spectral-kernel criterion

[
g_E(t):=\Lambda(E,1+it)
]
を考える。

### 定義 3.3（BSD bridge realization）

ある自己共役作用素 (D_E)、zero-free entire function (e^{P_E(z)})、および canonical isomorphism
[
\iota_E:E(\mathbb Q)\otimes_\mathbb Z\mathbb Q \xrightarrow{\sim} \ker D_E
]
が存在して
[
g_E(z)=e^{P_E(z)},\Delta_{D_E}(z)
]
が成り立つとき BSD bridge realization と呼ぶ。

### 定理 3.4

BSD bridge realization が存在すれば
[
\operatorname{ord}_{s=1}L(E,s)=\operatorname{rank}E(\mathbb Q)
]
が成り立つ。

#### 証明

completed 因子は中心で零・極を作らないので
[
\operatorname{ord}*{s=1}\Lambda(E,s)=\operatorname{ord}*{s=1}L(E,s).
]
(s=1+iz) と置けば
[
\operatorname{ord}*{s=1}\Lambda(E,s)=\operatorname{ord}*{z=0}g_E(z).
]
また
[
g_E(z)=e^{P_E(z)}\Delta_{D_E}(z)
]
だから
[
\operatorname{ord}*{z=0}g_E(z)=\operatorname{ord}*{z=0}\Delta_{D_E}(z).
]
定理 1.4 より
[
\operatorname{ord}*{z=0}\Delta*{D_E}(z)=\dim\ker D_E.
]
さらに (\ker D_E \cong E(\mathbb Q)\otimes\mathbb Q) なので
[
\dim\ker D_E=\operatorname{rank}E(\mathbb Q).
]
以上から
[
\operatorname{ord}_{s=1}L(E,s)=\operatorname{rank}E(\mathbb Q).
]
(\square)

---

## 3.3 BSD leading coefficient の exact reduction

(r:=\dim\ker D_E) とし、
[
D_E = 0_r \oplus D_E^\perp
]
と直交分解する。すると
[
\Delta_{D_E}(z)=z^r\Delta_{D_E^\perp}(z),
\qquad
\Delta_{D_E^\perp}(0)\neq 0.
]

したがって
[
g_E(z)=e^{P_E(z)}z^r\Delta_{D_E^\perp}(z).
]

(s=1+z) に戻すと
[
\Lambda(E,s)
============

e^{P_E(-i(s-1))},
(-i(s-1))^r,
\Delta_{D_E^\perp}(-i(s-1)).
]

### 命題 3.5

[
\frac{1}{r!}\Lambda^{(r)}(E,1)
==============================

(-i)^r e^{P_E(0)}\Delta_{D_E^\perp}(0).
]

#### 証明

上の式で ((s-1)^r) の係数を読むだけである。 (\square)

この式の意味は非常に明確です。
**BSD の full leading-term formula は、bridge kernel の外側の regularized determinant と arithmetic constant を一致させる問題**に落ちる。

つまり、rank 部分の後に残る本体は

[
\boxed{
(-i)^r e^{P_E(0)}\Delta_{D_E^\perp}(0)
\stackrel{?}{=}
\text{BSD の leading constant}
}
]

です。

ここで右辺は、通常の書き方では
[
\frac{\Omega_E,\mathrm{Reg}(E),#\Sha(E),\prod_p c_p}
{(#E(\mathbb Q)_{\mathrm{tors}})^2}
]
のような量になりますが、v89 的には **bridge 外側 determinant と算術定数の一致** と読むのが本質です。

---

## 3.4 BSD の最終式

v89 の BSD branch は、rank については exact に次へ落ちます：

\boxed{
\text{BSD-BRT}*E:\
\Lambda(E,1+iz)=e^{P_E(z)}\Delta*{D_E}(z),

が最後の等式です。

# 第IV章　Hodge branch

Clay/Deligne の記述では、Hodge 類は
[
H^{2p}(X,\mathbb Q)\cap H^{p,p}(X)
]
であり、Hodge conjecture は「任意の Hodge 類は algebraic cycles の類の有理線形結合である」という主張です。また Clay は、Hodge conjecture が特殊な場合、たとえば複素次元 (<4) では知られているが一般には未解決だと説明しています。([Clay Mathematics Institute][3])

## 4.1 Hodge bridge

[
\mathrm{Hdg}^p(X):=
H^{2p}(X,\mathbb Q)\cap H^{p,p}(X)
]
と置く。

cycle class map は
[
\mathrm{cl}^p_{\mathbb Q}:CH^p(X)_{\mathbb Q}\to \mathrm{Hdg}^p(X).
]

ここで algebraic side を
[
V_p:=CH^p(X)*{\mathbb Q}/\ker \mathrm{cl}^p*{\mathbb Q}
]
と置く。すると (\mathrm{cl}^p_{\mathbb Q}) は (V_p) を通って単射
[
T_p:V_p\hookrightarrow \mathrm{Hdg}^p(X)
]
を誘導する。

このとき Hodge conjecture はちょうど
[
T_p \text{ が全射}
]
である。

---

## 4.2 orthogonal decomposition

(\mathrm{Hdg}^p(X)) に任意の内積を入れ、(T_p^*) をその随伴とする。

### 定理 4.1

[
\mathrm{Hdg}^p(X)
=================

\operatorname{Im}T_p \oplus \ker T_p^*.
]

#### 証明

一般に
[
(\operatorname{Im}T_p)^\perp = \ker T_p^*.
]
有限次元なので
[
\mathrm{Hdg}^p(X)=\operatorname{Im}T_p\oplus(\operatorname{Im}T_p)^\perp
]
であるから
[
\mathrm{Hdg}^p(X)=\operatorname{Im}T_p\oplus\ker T_p^*.
]
(\square)

### 系 4.2

Hodge conjectureは
[
\ker T_p^*=0
]
と同値である。

#### 証明

Hodge conjectureは (\operatorname{Im}T_p=\mathrm{Hdg}^p(X)) であり、定理 4.1 によってこれは (\ker T_p^*=0) と同値。 (\square)

これはすでにかなり強いです。
Hodge conjectureは **bridge cokernel の消滅** に exact に落ちています。

---

## 4.3 Hodge-Dirac と obstruction Laplacian

Hodge-Dirac を
[
D_{X,p}:=
\begin{pmatrix}
0&T_p^*\
T_p&0
\end{pmatrix}
]
と定める。

定理 1.1 から
[
\ker D_{X,p}=\ker T_p\oplus \ker T_p^*.
]

しかし (T_p) は (V_p) 上単射なので (\ker T_p=0)。
したがって
[
\ker D_{X,p}=\ker T_p^*.
]

さらに obstruction Laplacian を
[
\Delta_{X,p}^+:=T_pT_p^*:\mathrm{Hdg}^p(X)\to \mathrm{Hdg}^p(X)
]
と定める。

定理 1.2 から
[
\ker \Delta_{X,p}^+=\ker T_p^*.
]

### 定理 4.3（v89 Hodge criterion）

Hodge conjectureは次と同値である：
[
\ker D_{X,p}=0,
]
[
\ker \Delta_{X,p}^+=0.
]

#### 証明

系 4.2 と
[
\ker D_{X,p}=\ker T_p^*,
\qquad
\ker \Delta_{X,p}^+=\ker T_p^*
]
を合わせればよい。 (\square)

これで Hodge は、**positive bridge obstruction operator の kernel 消滅問題**として exact に閉じました。

---

## 4.4 coercivity まで落とす

ここからさらに一段進めます。

### 定義 4.4

(\Delta_{X,p}^+) が coercive であるとは、ある (c>0) が存在して
[
\langle \Delta_{X,p}^+ h,h\rangle \ge c|h|^2
\qquad
(\forall h\in \mathrm{Hdg}^p(X))
]
が成り立つことをいう。

### 定理 4.5

(\Delta_{X,p}^+) が coercive なら Hodge conjecture が成り立つ。
さらに任意の Hodge 類 (h\in \mathrm{Hdg}^p(X)) には最小ノルム algebraic lift
[
v_{\min}(h):=T_p^*(\Delta_{X,p}^+)^{-1}h
]
が存在し、
[
T_p v_{\min}(h)=h,
\qquad
|v_{\min}(h)|\le c^{-1/2}|h|.
]

#### 証明

coercive なら (\Delta_{X,p}^+) は可逆である。よって (v_{\min}(h)) は定義される。

まず
[
T_p v_{\min}(h)
===============

# T_pT_p^*(\Delta_{X,p}^+)^{-1}h

# \Delta_{X,p}^+(\Delta_{X,p}^+)^{-1}h

h.
]
したがって全射であり、Hodge conjecture が従う。

次にノルム評価を示す。
coercivity と Cauchy–Schwarz から
[
c|u|^2 \le \langle \Delta_{X,p}^+u,u\rangle \le |\Delta_{X,p}^+u||u|
]
なので
[
|u|\le c^{-1}|\Delta_{X,p}^+u|.
]
これを (u=(\Delta_{X,p}^+)^{-1}h) に適用すると
[
|(\Delta_{X,p}^+)^{-1}h|\le c^{-1}|h|.
]
さらに
[
|v_{\min}(h)|^2
===============

\langle T_p^*(\Delta_{X,p}^+)^{-1}h,\ T_p^*(\Delta_{X,p}^+)^{-1}h\rangle
]
[
=

# \langle \Delta_{X,p}^+(\Delta_{X,p}^+)^{-1}h,\ (\Delta_{X,p}^+)^{-1}h\rangle

\langle h,(\Delta_{X,p}^+)^{-1}h\rangle
\le |h|\cdot |(\Delta_{X,p}^+)^{-1}h|
\le c^{-1}|h|^2.
]
よって
[
|v_{\min}(h)|\le c^{-1/2}|h|.
]
(\square)

これはかなり強い exact reduction です。
Hodge の最終残差は、ただ一つ

[
\boxed{
\Delta_{X,p}^+=T_pT_p^*
\text{ の coercivity / invertibility}
}
]

になりました。

# 第VI章　P vs NP branch

Clay の公式説明では、P vs NP は「解の正しさを速く確認できるなら、解自体も速く見つけられるか」という問題です。現在も未解決です。([Clay Mathematics Institute][5])

ここではこれを **不可視 sector・散逸・section defect** の言葉に書き換えます。

## 6.1 NP を witness bundle として書く

関係
[
R(x,w)\in{0,1}
]
が多項式時間で判定可能で、かつ
[
|w|\le p(|x|)
]
なる多項式 (p) があるとする。

各入力 (x) に対して witness fiber を
[
\mathfrak I_x:={,w\mid R(x,w)=1,}
]
と定める。

すると言語 (L) は
[
x\in L
\iff
\mathfrak I_x\neq\varnothing.
]

LoNalogy 的には

* visible sector：入力 (x)
* invisible sector：fiber (\mathfrak I_x)
* bridge：((x,w)) で (R(x,w)=1) が成立する locus

である。

---

## 6.2 NP = 存在射影

bridge relation
[
\mathfrak B:={(x,w)\mid R(x,w)=1}
]
とし、射影
[
\pi:\mathfrak B\to \Sigma^*,
\qquad
\pi(x,w)=x
]
を取る。

### 命題 6.1

[
L=\pi(\mathfrak B).
]

#### 証明

[
x\in \pi(\mathfrak B)
\iff
\exists w\ \text{such that }(x,w)\in \mathfrak B
\iff
\exists w\ \text{such that }R(x,w)=1
\iff
x\in L.
]
(\square)

したがって
[
\boxed{
NP = \exists\text{-projection of an efficiently checkable bridge relation}
}
]

です。

## 6.3 散逸としての forgetful map

forgetful map
[
\mathrm{For}:(x,w)\mapsto x
]

多数の witness を一つの visible instance へ潰してしまう。

この意味で decision は
[

]

verification は bridge 上の局所判定、decision は hidden fiber を忘れた後の像。
これが LoNalogy 的な P vs NP の中身です。

## 6.4 SAT の exact section criterion

ここは exact に閉じます。

(\mathrm{SAT}) の各式 (\varphi) に対して satisfying assignments の集合を
[
\mathfrak I_\varphi
]
とする。

空 fiber も扱うため、拡張 fiber を
[
\widetilde{\mathfrak I}*\varphi
:=
\begin{cases}
\mathfrak I*\varphi,& \mathfrak I_\varphi\neq\varnothing,\
{\bot},& \mathfrak I_\varphi=\varnothing
\end{cases}
]
と定める。ここで (\bot) は “unsat” を表す特別な点。

### 定義 6.2

SAT witness bundle の polynomial-time total section とは、全ての論理式 (\varphi) に対して
[
\sigma(\varphi)\in \widetilde{\mathfrak I}*\varphi
]
を返す多項式時間写像
[
\sigma:\mathrm{Form}\to \bigsqcup*\varphi \widetilde{\mathfrak I}_\varphi
]
である。

### 定理 6.3

[
\mathrm{SAT}\in P
\iff
\text{SAT witness bundle が polynomial-time total section を持つ}.
]

#### 証明

((\Rightarrow))
SAT が多項式時間で判定できるとする。
まず (\varphi) が satisfiable か判定する。unsat なら (\bot) を返す。sat なら self-reduction を行う。変数 (x_1,\dots,x_n) について、(\varphi|_{x_1=0}) が satisfiable かを判定し、yes なら (x_1=0)、no なら (x_1=1) と固定する。これを全変数について繰り返せば、多項式回数の SAT 判定で一つの充足割当てが得られる。よって polynomial-time total section が構成できる。

((\Leftarrow))
polynomial-time total section (\sigma) があるとする。
(\sigma(\varphi)=\bot) なら unsat、(\sigma(\varphi)\neq\bot) ならその assignment を評価して sat か確認する。section の定義により、これは正しい decision algorithm である。よって (\mathrm{SAT}\in P)。

(\square)

SAT は NP 完全なので、この定理は

[
\boxed{
P=NP
\iff
\text{SAT witness bundle が polynomial-time total section を持つ}
}
]

を与えます。

ここで初めて、P vs NP の LoNalogy 的本体が完全に見えます。

[
\boxed{
\text{難しさの核は yes/no ではなく、
hidden witness fiber への efficient section の有無}
