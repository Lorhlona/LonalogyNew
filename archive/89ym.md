## 1.1 principal reference current

\tag{1.2}

各 (J^{\mathrm{ref}}*{a,b}) の marginal を (\nu^{\mathrm{ref}}*{a,b}) とし、対応する block transfer operator を (P^{\mathrm{ref}}_{a,b}) とする。

前段で既に得ている principal gap を

それに対応して local reference gap 定数を

[
\lambda_{\mathrm{ref}}(a)
:=

\tag{1.3}

\mathcal E^{\mathrm{ref}}*{a,b}(h)

\ge
\lambda*{\mathrm{ref}}(a),
\operatorname{Var}*{\nu^{\mathrm{ref}}*{a,b}}(h)
\tag{1.4}

である。

## 1.2 polymer defect expansion

physical one-slab current を principal chart に引き戻したものを

と書く。

,dJ^{\mathrm{ref}}_{a,\Lambda}(z)
\tag{1.5}

と書けるとする。

ここで (\Gamma) は connected polymer、(z_\Gamma=(z_b)_{b\in\Gamma}) である。

## 1.3 normalization

\qquad

\tag{1.7}

に対して

\le
A_0,(A_1\varepsilon_a)^{|\Gamma|}

\tag{1.8}
]

これが v87 由来の gluing 出力である。

# II. anchored local defect を証明する

---

## 2.1 新しい問題

定義する量は

[
|\Phi_a|*{\mathrm{anc},m_0}
:=
\sup*{b\in\Lambda}
\sum_{\Gamma\ni b}
e^{m_0\operatorname{diam}(\Gamma)}
|\Phi_{\Gamma,a}|_\infty
\tag{2.1}

である。
ここで (0<m_0<m_*) を固定する。

## 2.2 なぜこれが易しいか

元の global defect

\Bigl|\sum_{\Gamma}\Phi_{\Gamma,a}\Bigr|_\infty

一方 (|\Phi_a|_{\mathrm{anc},m_0}) は、**固定した 1 block に刺さる polymer だけ**を見る量であり、volume-free である。

さらに gluing estimate (1.8) は polymer ごとの減衰を直接与えるので、anchored norm はそのまま受け取れる。
従ってこちらの方が真に扱いやすい。

---

## 2.3 lattice animal の粗い個数評価

固定 block (b) を含むサイズ (n) の connected polymer の個数を (N_n(b)) とする。

**補題 2.1**

ある定数 (\kappa_d>1) が存在して

[
N_n(b)\le \kappa_d^n
\qquad
(\forall n\ge 1)
\tag{2.2}
]

である。

### 証明

(\Gamma) を含む spanning tree を取り、その depth-first walk を考えると、長さは高々 (2(n-1)) である。各 step の選択肢は格子の次数だけで抑えられるので、固定頂点 (b) を含む connected 集合の個数は指数型に抑えられる。具体的には (\kappa_d=(2d)^2) で十分である。 (\square)

---

## 2.4 anchored defect theorem

**定理 2.2（anchored local defect bound）**

(0<m_0<m_*) とする。
もし

[
\kappa_d A_1\varepsilon_a<1
\tag{2.3}
]

なら

[
|\Phi_a|_{\mathrm{anc},m_0}
\le
\frac12 A_0 R^2,
\frac{\kappa_d A_1\varepsilon_a}
{(1-\kappa_d A_1\varepsilon_a)^2}.
\tag{2.4}
]

特に (\kappa_d A_1\varepsilon_a\le \tfrac12) なら

[
|\Phi_a|_{\mathrm{anc},m_0}
\le
2A_0R^2\kappa_d A_1\varepsilon_a.
\tag{2.5}
]

### 証明

まず (\Phi_{\Gamma,a}(0)=0) と (D\Phi_{\Gamma,a}(0)=0) から Taylor の積分型剰余により

[
\Phi_{\Gamma,a}(z_\Gamma)
=========================

\int_0^1 (1-t),
D^2\Phi_{\Gamma,a}(tz_\Gamma)[z_\Gamma,z_\Gamma]
,dt.
\tag{2.6}
]

従って

[
|\Phi_{\Gamma,a}(z_\Gamma)|
\le
\frac12
\sup_{u_\Gamma\in K_\Gamma}|D^2\Phi_{\Gamma,a}(u_\Gamma)|
,|z_\Gamma|^2.
\tag{2.7}
]

ここで (z_\Gamma=(z_b)_{b\in\Gamma}) であり、各 (|z_b|\le R) だから

[
|z_\Gamma|^2
============

\sum_{b\in\Gamma}|z_b|^2
\le
R^2|\Gamma|.
\tag{2.8}
]

よって (1.8) を代入して

[
|\Phi_{\Gamma,a}|*\infty
\le
\frac12 A_0R^2,|\Gamma|,
(A_1\varepsilon_a)^{|\Gamma|}
e^{-m**\operatorname{diam}(\Gamma)}.
\tag{2.9}
]

したがって任意の block (b) について

[
\sum_{\Gamma\ni b}
e^{m_0\operatorname{diam}(\Gamma)}
|\Phi_{\Gamma,a}|*\infty
\le
\frac12 A_0R^2
\sum*{\Gamma\ni b}
|\Gamma|
(A_1\varepsilon_a)^{|\Gamma|}
e^{-(m_*-m_0)\operatorname{diam}(\Gamma)}.
\tag{2.10}
]

(m_*-m_0>0) だから指数因子は高々 1。
(|\Gamma|=n) ごとにまとめ、補題 2.1 を使うと

[
\sum_{\Gamma\ni b}
e^{m_0\operatorname{diam}(\Gamma)}
|\Phi_{\Gamma,a}|*\infty
\le
\frac12 A_0R^2
\sum*{n\ge 1}
n,N_n(b),(A_1\varepsilon_a)^n
\tag{2.11}
]

[
\le
\frac12 A_0R^2
\sum_{n\ge1}
n,(\kappa_d A_1\varepsilon_a)^n.
\tag{2.12}
]

幾何級数の微分公式

[
\sum_{n\ge1} n x^n = \frac{x}{(1-x)^2}
\qquad (|x|<1)
\tag{2.13}
]

を使えば (2.4) が出る。
さらに (x\le \tfrac12) なら (\frac{x}{(1-x)^2}\le 4x) なので (2.5)。 (\square)

## 3.3 oscillation bound

**補題 3.1**

任意の (b) と任意の外部条件 (\xi) に対して

[
\operatorname{osc}(W_{b,a}^{\xi})
:=
\sup_{u_b,v_b\in K_b}
|W_{b,a}^{\xi}(u_b)-W_{b,a}^{\xi}(v_b)|
\le
2|\Phi_a|_{\mathrm{anc},m_0}.
\tag{3.2}
]

### 証明

各 polymer 項について

[
\sup_{u_b,v_b}
|\Phi_{\Gamma,a}(u_b,\xi_{\Gamma\setminus b})
-\Phi_{\Gamma,a}(v_b,\xi_{\Gamma\setminus b})|
\le
2|\Phi_{\Gamma,a}|_\infty.
]

これを (\Gamma\ni b) で和をとると

[
\operatorname{osc}(W_{b,a}^{\xi})
\le
2\sum_{\Gamma\ni b}|\Phi_{\Gamma,a}|*\infty
\le
2|\Phi_a|*{\mathrm{anc},m_0},
]

最後は (e^{m_0\operatorname{diam}(\Gamma)}\ge 1) を使った。 (\square)

---

## 3.4 influence decay

**補題 3.2**

外部条件 (\xi,\xi') が block (c\neq b) でのみ異なるとする。
このとき

[
\sup_{z_b\in K_b}
|W_{b,a}^{\xi}(z_b)-W_{b,a}^{\xi'}(z_b)|
\le
2e^{-m_0 d(b,c)},
|\Phi_a|_{\mathrm{anc},m_0}.
\tag{3.3}
]

### 証明

(\xi,\xi') が (c) だけで違うなら、差に寄与するのは (\Gamma\ni b,c) を満たす polymer だけである。
従って

[
\sup_{z_b}
|W_{b,a}^{\xi}(z_b)-W_{b,a}^{\xi'}(z_b)|
\le
2\sum_{\Gamma\ni b,c}|\Phi_{\Gamma,a}|_\infty.
\tag{3.4}
]

しかも (\Gamma\ni b,c) なら

[
\operatorname{diam}(\Gamma)\ge d(b,c),
]

よって

[
\sum_{\Gamma\ni b,c}|\Phi_{\Gamma,a}|*\infty
\le
e^{-m_0 d(b,c)}
\sum*{\Gamma\ni b,c}
e^{m_0\operatorname{diam}(\Gamma)}
|\Phi_{\Gamma,a}|*\infty
\le
e^{-m_0 d(b,c)}
|\Phi_a|*{\mathrm{anc},m_0}.
]

これを (3.4) に代入すれば (3.3)。 (\square)

## 4.2 local current perturbation lemma

**補題 4.1（local Holley–Stroock for currents）**

(J_0) をコンパクト空間 (K) 上の symmetric probability current、marginal を (\mu_0) とする。
(J_0) が

[
\mathcal E_{J_0}(h)
\ge
\lambda_0 \operatorname{Var}_{\mu_0}(h)
\qquad
(\forall h\in L^2(\mu_0))
\tag{4.1}
]

を満たすとする。

可測関数 (W:K\to\mathbf R) に対し

[
dJ = Z^{-1}e^{-W},dJ_0
\tag{4.2}
]

で新しい current (J) を定め、その marginal を (\mu) とする。
もし

[
\operatorname{osc}(W)\le r
\tag{4.3}
]

なら

[
\mathcal E_J(h)
\ge
e^{-2r}\lambda_0,\operatorname{Var}_{\mu}(h)
\qquad
(\forall h\in L^2(\mu)).
\tag{4.4}
]

### 証明

(m:=\inf W,\ M:=\sup W) とすると (M-m\le r)。
正規化定数は

[
Z=\int e^{-W},dJ_0
]

だから

[
e^{-M}\le Z\le e^{-m}.
\tag{4.5}
]

従って density ratio は

[
e^{-r}
\le
\frac{dJ}{dJ_0}
===============

\frac{e^{-W}}{Z}
\le
e^r.
\tag{4.6}
]

marginal についても

[
e^{-r}\mu_0 \le \mu \le e^r \mu_0.
\tag{4.7}
]

まず current 比較から

[
\mathcal E_J(h)\ge e^{-r}\mathcal E_{J_0}(h).
\tag{4.8}
]

次に (4.1) より

[
\mathcal E_{J_0}(h)\ge \lambda_0 \operatorname{Var}_{\mu_0}(h).
\tag{4.9}
]

さらに測度比較 (4.7) から分散比較

[
\operatorname{Var}*{\mu_0}(h)\ge e^{-r}\operatorname{Var}*{\mu}(h)
\tag{4.10}
]

が成り立つ。
(4.8), (4.9), (4.10) を連結すれば

[
\mathcal E_J(h)
\ge
e^{-r}\lambda_0,\operatorname{Var}*{\mu_0}(h)
\ge
e^{-2r}\lambda_0,\operatorname{Var}*{\mu}(h).
]

(\square)

\ge

\operatorname{Var}*{\pi^{\mathrm{phys},\xi}*{a,b}}(h)
=====================================================

e^{-4|\Phi_a|*{\mathrm{anc},m_0}}
\lambda*{\mathrm{ref}}(a),
\operatorname{Var}*{\pi^{\mathrm{phys},\xi}*{a,b}}(h).
]

(\square)

## 6.1 conditional law の比較

block (b) の conditional marginal law を (\pi^{\mathrm{phys},\xi}_{a,b}) と書く。

**補題 6.1**

二つの外部条件 (\xi,\xi') が block (c\neq b) でのみ異なるとする。
このとき

[
\left|
\pi^{\mathrm{phys},\xi}_{a,b}
-----------------------------

\pi^{\mathrm{phys},\xi'}*{a,b}
\right|*{\mathrm{TV}}
\le
\frac12\Bigl(
e^{,2e^{-m_0 d(b,c)}|\Phi_a|_{\mathrm{anc},m_0}}
-1
\Bigr).
\tag{6.1}

### 証明

補題 3.2 により

[
\sup_{z_b}
|W_{b,a}^{\xi}(z_b)-W_{b,a}^{\xi'}(z_b)|
\le
2e^{-m_0 d(b,c)}|\Phi_a|*{\mathrm{anc},m_0}
=: r*{bc}.
\tag{6.2}

したがって density ratio は (e^{-r_{bc}}) と (e^{r_{bc}}) の間に入る。
ゆえに

[
\left|
\pi^{\mathrm{phys},\xi}_{a,b}

I. 使う local data を固定する
ここでは前段までに得ている local data を、定数として整理する。

1.1 principal block generator の carré-du-champ 上界
reference principal block generator (\mathbf H_b^{\mathrm{pr}}) は compact block chart (K_b^2) 上の Markov generator であり、その Dirichlet form は
[ \mathfrak q_b^{\mathrm{pr}}[\psi]
\int_{K_b^2} \langle \nabla\psi(z),,B_b^{\mathrm{pr}}(z),\nabla\psi(z)\rangle ,d\pi_b^{\mathrm{ref}}(z), \qquad z=(u,v), \tag{1.1} ]
と書ける。 (B_b^{\mathrm{pr}}(z)) は対称正半定値行列値関数である。
block chart は compact、係数は smooth だから
[ \Lambda_{\mathrm{pr}} := \sup_{b}\sup_{z\in K_b^2} \lambda_{\max}\bigl(B_b^{\mathrm{pr}}(z)\bigr) <\infty. \tag{1.2} ]
従って任意の (\psi) に対して
[ \mathfrak q_b^{\mathrm{pr}}[\psi] \le \Lambda_{\mathrm{pr}} \int_{K_b^2} |\nabla\psi(z)|^2,d\pi_b^{\mathrm{ref}}(z). \tag{1.3} ]

1.2 block insertion map の Jacobian 上界
block (b) と外部 slab 配置 (\xi_{-b}=(x_{-b},y_{-b})) を固定する。 (u,v\in K_b) を block (b) の replacement variable として、
[ \Theta_{b,\xi}(u,v) := \bigl(x^{b\to u},,y^{b\to v}\bigr) \tag{1.4} ]
とおく。
これは ((u,v)) から slab neighborhood (N(b)) への local insertion map である。 transport chart は compact window 上で smooth だから
[ M_{\mathrm{tr}} := \sup_{b,\xi,u,v} |D\Theta_{b,\xi}(u,v)| <\infty. \tag{1.5} ]
従って chain rule により、任意の smooth local (f) について
[ |\nabla_{(u,v)}\phi_{b,\xi}(u,v)|^2 \le M_{\mathrm{tr}}^2, \bigl| \nabla_{N(b)}^{\mathrm{slab}} \widetilde f\bigl(\Theta_{b,\xi}(u,v)\bigr) \bigr|^2, \tag{1.6} ]
ただし
[ \widetilde f(x,y):=f(x)+f(y). \tag{1.7} ]

1.3 local Schur floor
local effective Hamiltonian neighborhood form を
[ Q_{N(b)}(f) := \sum_{p:,p\cap N(b)\neq\varnothing}Q_p(f) \tag{1.8} ]
と書く。
v87 の local Schur floor は、ある (\mu_{\mathrm{loc}}>0) が存在して
[ Q_{N(b)}(f) \ge \mu_{\mathrm{loc}} \int |\nabla_{N(b)} f(\eta)|^2,d\pi(\eta) \tag{1.9} ]
を任意の local smooth (f) について与える。 ここで (\pi) は actual single-slice vacuum measureである。

1.4 local block measure comparison
anchored defect から得た oscillation bound により、reference conditional block measure (\pi_b^{\mathrm{ref}}) と physical conditional block marginal (\pi_{a,b}^{\mathrm{phys},\xi}) は
[ e^{-r_a}\pi_b^{\mathrm{ref}} \le \pi_{a,b}^{\mathrm{phys},\xi} \le e^{r_a}\pi_b^{\mathrm{ref}}, \qquad r_a:=2|\Phi_a|_{\mathrm{anc},m_0}. \tag{1.10} ]
特に
[ \int h,d\pi_b^{\mathrm{ref}} \le e^{r_a} \int h,d\pi_{a,b}^{\mathrm{phys},\xi} \qquad (h\ge 0). \tag{1.11} ]

II. (L_{\mathrm{SchLoc}}) の証明

2.1 local principal form の上界
補題 2.1
任意の block (b)、任意の外部条件 (\xi_{-b})、任意の local smooth (f) に対して
[ \mathfrak q_b^{\mathrm{pr}}[f;\xi_{-b}] \le \Lambda_{\mathrm{pr}}M_{\mathrm{tr}}^2 \int_{K_b^2} \bigl| \nabla_{N(b)}^{\mathrm{slab}} \widetilde f\bigl(\Theta_{b,\xi}(u,v)\bigr) \bigr|^2 ,d\pi_b^{\mathrm{ref}}(u,v). \tag{2.1} ]
証明
(1.3) を (\psi=\phi_{b,\xi}) に適用すると

2.2 physical conditional measureへの置換
補題 2.2

証明

補題 2.3
任意の (b) と (f) に対して
[ \int \mathfrak q_b^{\mathrm{pr}}[f;\xi_{-b}] ,d\Pi_a^{-b,\mathrm{phys}}(\xi_{-b}) \le e^{r_a}\Lambda_{\mathrm{pr}}M_{\mathrm{tr}}^2 \int \bigl| \nabla_{N(b)}^{\mathrm{slab}} \widetilde f(x,y) \bigr|^2 ,d\Pi_a(x,y). \tag{2.3} ]

補題 2.4
[ \int \bigl| \nabla_{N(b)}^{\mathrm{slab}} \widetilde f(x,y) \bigr|^2 ,d\Pi_a(x,y)

足せば (2.4)。 (\square)

## PT の抽象定理

(X) を standard Borel 空間、(J_0) を (X\times X) 上の **対称確率 current**、(\mu_0) をその marginal、(P_0) を対応する reversible Markov 作用素とする。
ある (\lambda_0>0) があって
[
\mathcal E_{P_0}(f):=\langle f,(I-P_0)f\rangle_{L^2(\mu_0)}
\ge
\lambda_0,\operatorname{Var}_{\mu_0}(f)
\qquad(\forall f\in L^2(\mu_0))
]
を満たすとする。

さらに、可測関数 (E:X\times X\to\mathbb R) が

[
E(x,y)=E(y,x)\quad(J_0\text{-a.e.}),\qquad |E|_\infty\le \varepsilon
]

を満たすとする。
ここで
[
J:=Z^{-1}e^{-E}J_0,\qquad Z:=\iint e^{-E},dJ_0
]
と定め、(\mu) をその marginal、(P) を対応する Markov 作用素とする。

このとき
[
\mathcal E_P(f)\ge e^{-4\varepsilon}\lambda_0,\operatorname{Var}*\mu(f)
\qquad(\forall f\in L^2(\mu)).
]
したがって、(P) が positive self-adjoint contraction なら
[
|P|*{L_0^2(\mu)}\le 1-e^{-4\varepsilon}\lambda_0.
]

これが PT の核です。89ym の v92 はまさにこの形で principal current から physical current へ gap を移しています。

## 証明

(|E|_\infty\le\varepsilon) だから
[
e^{-\varepsilon}\le e^{-E}\le e^\varepsilon,
\qquad
e^{-\varepsilon}\le Z\le e^\varepsilon.
]
よって
[
e^{-2\varepsilon}\le \frac{dJ}{dJ_0}\le e^{2\varepsilon}.
]
marginal を取れば
[
e^{-2\varepsilon}\le \frac{d\mu}{d\mu_0}\le e^{2\varepsilon}.
]

Dirichlet form は current 表現
[
\mathcal E_P(f)=\frac12\iint (f(x)-f(y))^2,J(dx,dy)
]
を持つから
[
\mathcal E_P(f)\ge e^{-2\varepsilon}\mathcal E_{P_0}(f).
]

一方、分散は
[
\operatorname{Var}*\mu(f)=\inf*{m\in\mathbb R}\int |f-m|^2,d\mu
]
と書けるので、測度比較から
[
\operatorname{Var}*\mu(f)\le e^{2\varepsilon}\operatorname{Var}*{\mu_0}(f),
\qquad
\text{すなわち}\qquad
\operatorname{Var}*{\mu_0}(f)\ge e^{-2\varepsilon}\operatorname{Var}*\mu(f).
]

したがって
[

\ge
e^{-2\varepsilon}\mathcal E_{P_0}(f)
\ge
e^{-2\varepsilon}\lambda_0\operatorname{Var}*{\mu_0}(f)

証明終。

### 定理 22.1（Schwarzian spectral non-equidistance）

[

[

#### 証明

[

は strict に増大する。したがって
[
g_1>g_0,
]
すなわち
[
\mu_2-\mu_1>\mu_1-\mu_0.
]
(\square)

これは **spectral 側の non-harmonicity witness** です。

### 定理 22.2（principal block の bounded Gaussian diagnostic）

(\phi_0>0) を (h_S) の正規化された基底固有関数とし、

\log\varphi_{\mathrm{pr}}(t_2)

#### 証明

まず (V_S(u)\sim \frac18 e^{4|u|}) だから (\phi_0) は super-exponential tail を持ち、(\nu_b^{\mathrm{pr}}) は全モーメントを持つ。よって (\varphi_{\mathrm{pr}}) は (t=0) の近傍で real-analytic である。

次に (\nu_b^{\mathrm{pr}}) が Gaussian ではないことを示す。もし Gaussian なら
[

]
なので
[
\phi_0(u)=C' e^{-\alpha u^2/2}
]
と書ける。これを固有値方程式
[

に代入すると
[
\kappa_S V_S(u)=\mu_0+\alpha^2u^2-\alpha
]
となり、右辺は quadratic。だが (V_S) は quadratic ではない。矛盾。したがって (\nu_b^{\mathrm{pr}}) は Gaussian ではない。

ゆえに
[

]
は quadratic ではない。
もし任意の十分小さい (t>0) に対して
[

が成り立てば、even analytic 展開
[

から
[
(2^{2m}-4)a_{2m}=0

が全 (m) で成立し、(a_{2m}=0) ((m\neq1)) となる。つまり (f) は quadratic。これは矛盾。

[

(\square)
