# 第 I 部　strict kernel と rank \(5\)

## 1. strict kernel equation の解析

### 定義 1.1（strict kernel equation）
\[
\boxed{
\nu_{\rm br}(1-k)^2(1+k)=2
}
\]
を strict kernel equation と呼ぶ。

---

### 定理 1.2（存在と一意性） [C]
\[
\nu_{\rm br}>2
\]
なら strict kernel equation は
\[
(0,1)
\]
に一意の解 \(k_{\rm ker}\) を持つ。

#### 証明
\[
g(k):=(1-k)^2(1+k),\qquad 0<k<1
\]
と置く。  
すると
\[
g(k)=(1-k)(1-k^2)
\]
であり、
\[
g'(k)=-(1-k^2)-2k(1-k)=-(1-k)(1+3k)<0
\]
だから \(g\) は \((0,1)\) で厳密単調減少である。  
さらに
\[
g(0)=1,\qquad \lim_{k\to1^-}g(k)=0.
\]
\(\nu_{\rm br}>2\) なら
\[
0<\frac{2}{\nu_{\rm br}}<1
\]
だから、中間値の定理より
\[
g(k)=\frac{2}{\nu_{\rm br}}
\]
は \((0,1)\) にただ一つの解を持つ。 \(\square\)

---

### 定理 1.3（self-dual threshold） [C]
self-dual point は
\[
x=0\iff k=\frac{1}{\sqrt2}
\]
であり、
\[
\nu_{\rm br}<8+4\sqrt2
\]
なら
\[
k_{\rm ker}<\frac{1}{\sqrt2},
\qquad
x_{\rm ker}=2k_{\rm ker}^2-1<0.
\]

#### 証明
\[
x=2k^2-1
\]
だから \(x=0\) は \(k=1/\sqrt2\) と同値である。  
また
\[
g\!\left(\frac{1}{\sqrt2}\right)
=
\left(1-\frac{1}{\sqrt2}\right)^2\left(1+\frac{1}{\sqrt2}\right)
=
\frac{1}{8+4\sqrt2}.
\]
従って
\[
\nu_{\rm br}g\!\left(\frac{1}{\sqrt2}\right)<2
\iff
\nu_{\rm br}<8+4\sqrt2.
\]
\(g\) は単調減少だから、このとき root は \(1/\sqrt2\) より左にある。 \(\square\)

---

### 定理 1.4（exact trigonometric formula） [C]
\[
\nu>2
\]
に対して strict kernel root は
\[
\boxed{
k_{\rm ker}(\nu)
=
\frac13+\frac43
\cos\!\left(
\frac{2\pi-\arccos\!\left(\frac{27}{8\nu}-1\right)}{3}
\right)
}
\]
で与えられる。

#### 証明
strict kernel equation を展開すると
\[
\nu(1-k-k^2+k^3)=2,
\]
すなわち
\[
k^3-k^2-k+1-\frac{2}{\nu}=0.
\]
ここで
\[
k=y+\frac13
\]
と置くと depressed cubic
\[
y^3-\frac43 y+\frac{16}{27}-\frac{2}{\nu}=0
\]
を得る。さらに
\[
y=\frac43\cos\theta
\]
と置くと
\[
y^3-\frac43 y=\frac{16}{27}\cos 3\theta
\]
だから
\[
\cos 3\theta=\frac{27}{8\nu}-1.
\]
\((0,1)\) に入る branch を選ぶと
\[
3\theta=2\pi-\arccos\!\left(\frac{27}{8\nu}-1\right)
\]
となり、主張の式が従う。 \(\square\)

---

### 定理 1.5（\(\nu\)-単調性） [C]
\[
\boxed{
\frac{dk_{\rm ker}}{d\nu}
=
\frac{1-k_{\rm ker}^2}{\nu(1+3k_{\rm ker})}>0
}
\]
である。

#### 証明
\[
\nu g(k)=2,\qquad g(k)=(1-k)^2(1+k)
\]
を \(\nu\) で微分すると
\[
g(k)+\nu g'(k)\frac{dk}{d\nu}=0.
\]
ここで
\[
g'(k)=-(1-k)(1+3k)
\]
だから
\[
\frac{dk}{d\nu}
=
-\frac{g(k)}{\nu g'(k)}
=
\frac{(1-k)^2(1+k)}{\nu(1-k)(1+3k)}
=
\frac{1-k^2}{\nu(1+3k)}.
\]
\(0<k<1\) より右辺は正である。 \(\square\)

---

### 系 1.6（physical \(SU(5)\) split） [C]
\[
(r,s)=(3,2)
\]
では
\[
\nu_{\rm br}=2rs=12,
\]
よって
\[
12(1-k)^2(1+k)=2
\]
の一意解が strict kernel である。  
対応する
\[
x_{\rm ker}=2k_{\rm ker}^2-1
\]
は負であり、strict kernel は self-dual 直下にある。 \(\square\)

## 2. rank \(5\) の強制

### 定理 2.1（up-type Yukawa cubic criterion） [C]
\[
\Lambda^2V\otimes\Lambda^2V\otimes V\to\det V
\]
が determinant-valued invariant として存在する必要十分条件は
\[
\dim V=5
\]
である。

#### 証明
自然外積
\[
(u_1\wedge u_2)\otimes(v_1\wedge v_2)\otimes w
\longmapsto
u_1\wedge u_2\wedge v_1\wedge v_2\wedge w
\]
は
\[
\Lambda^2V\otimes\Lambda^2V\otimes V\to\Lambda^5V
\]
を与える。  
これが \(\det V=\Lambda^{\dim V}V\) の値を取る invariant として読むためには
\[
\Lambda^5V\cong\Lambda^{\dim V}V
\]
でなければならない。従って
\[
\dim V=5.
\]
逆に \(\dim V=5\) ならこの写像がそのまま determinant-valued invariant になる。 \(\square\)

---

### 命題 2.2（anomaly cancellation criterion） [C]
\(SU(N)\) に対し
\[
A(\Lambda^2V)=N-4,\qquad A(V)=1
\]
とすると
\[
A(\Lambda^2V)+A(V^*)=(N-4)-1=N-5.
\]
従って
\[
A(\Lambda^2V)+A(V^*)=0
\iff
N=5.
\]

#### 証明
\(A(V^*)=-A(V)\) を用いれば一行で従う。 \(\square\)

---

### 系 2.3（rank \(5\) forced） [C]

## 3. Schur complement と reciprocity

### 定義 3.1（full quadratic kernel）
visible 変数 \(v\) と idea/hidden 変数 \(h\) に対し、full quadratic action を
\[
S(v,h)
=
\frac12\langle v,L_{\rm vis}v\rangle
+
\Re\langle v,Wh\rangle
+
\frac12\langle h,L_{\rm idea}h\rangle
\]
で定める。  
ここで \(L_{\rm idea}\) は正定値とする。

---

### 定理 3.2（Schur reduction theorem） [C]
hidden variable \(h\) を積分消去すると、visible effective action は
\[
S_{\rm eff}(v)
=
\frac12\langle v,K_{\rm vis}^{\rm red} v\rangle
\]
で与えられ、その kernel は
\[
\boxed{
K_{\rm vis}^{\rm red}
=
L_{\rm vis}-W L_{\rm idea}^{-1}W^\dagger
}
\]
である。

#### 証明
平方完成を行う。  
\[
h'
=
h+L_{\rm idea}^{-1}W^\dagger v
\]
と置けば
\[
S(v,h)
=
\frac12\langle v,L_{\rm vis}v\rangle
-
\frac12\langle v,WL_{\rm idea}^{-1}W^\dagger v\rangle
+
\frac12\langle h',L_{\rm idea}h'\rangle.
\]
最後の項は \(h'\) にのみ依存するので、Gaussian 積分で定数因子に吸収される。  
従って visible effective action の quadratic part は
\[
\frac12\langle v,(L_{\rm vis}-W L_{\rm idea}^{-1}W^\dagger)v\rangle
\]
である。 \(\square\)

---

### 系 3.3（Born-like response formula） [C]
detector \(D_i\) に対する response を
\[
\mathcal R_i:=D_i (K_{\rm vis}^{\rm red})^{-1} D_i^\dagger
\]
とすると、normalized readout
\[
p_i=\frac{\mathcal R_i}{\sum_j \mathcal R_j}
\]
は reduced visible theory の Born-like probability を与える。

#### 証明
\(K_{\rm vis}^{\rm red}\) が effective covariance inverse だから、二次 Gaussian readout の強度は
\[
D_i (K_{\rm vis}^{\rm red})^{-1} D_i^\dagger
\]
で与えられる。正規化すればよい。 \(\square\)

---

### 定理 3.4（RG reciprocity theorem） [C]
\[
\gamma_M(\mu):=\mu\frac{d}{d\mu}\log M_C(\mu),\qquad
\gamma_\sigma(\mu):=\mu\frac{d}{d\mu}\log \|\sigma_{\rm br}(\mu)\|
\]
とし、
\[
\gamma_M(\mu)+\gamma_\sigma(\mu)=0
\qquad(\forall\mu)
\]
かつある基準点 \(\mu_0\) で
\[
M_C(\mu_0)\,\|\sigma_{\rm br}(\mu_0)\|=\Lambda_*
\]
とする。  
このとき全 RG 軌道上で
\[
\boxed{
M_C(\mu)\,\|\sigma_{\rm br}(\mu)\|=\Lambda_*
}
\]
が成り立つ。

#### 証明
\[
\mu\frac{d}{d\mu}\log\bigl(M_C(\mu)\,\|\sigma_{\rm br}(\mu)\|\bigr)
=
\gamma_M(\mu)+\gamma_\sigma(\mu)=0.
\]
ゆえに積
\[
M_C(\mu)\,\|\sigma_{\rm br}(\mu)\|
\]
は \(\mu\) に依らず定数である。基準点でその値は \(\Lambda_*\) だから全軌道で
\[
M_C(\mu)\,\|\sigma_{\rm br}(\mu)\|=\Lambda_*.
\]
\(\square\)

---

### 系 3.5（木村--テブナン原理の解析版） [C]

# 第 III 部　entry と gluing

## 4. transduction と local minimizer

### 仮定 4.1（manifold source vanishing）
local phase family \(s_{j,x}(A;g,\widetilde R)\) に対し
\[
D_A s_{j,x}(0;g,0)=0
\qquad(\forall j,\forall x,\forall g)
\]
を仮定する。

### 仮定 4.2（regularity）
\(s_{j,x}\) は \(C^3\) であり、
\[
\sup_{j,x,g,\|\widetilde R\|\le\delta}
\left\|
\partial_{\widetilde R}D_As_{j,x}(0;g,\widetilde R)
\right\|
\le C_{\rm tr}
\]
を満たす。

---

### 定理 4.3（bundle transduction estimate） [C]
仮定 4.1, 4.2 の下で
\[
\boxed{
\|D_A s_{j,x}(0;g,\widetilde R)\|
\le
C_{\rm tr}\|\widetilde R\|
}
\]
が成り立つ。

#### 証明
\[
F_{j,x,g}(\widetilde R):=D_A s_{j,x}(0;g,\widetilde R)
\]
と置くと仮定 4.1 により \(F_{j,x,g}(0)=0\)。  
Banach 空間の平均値表示より
\[
F_{j,x,g}(\widetilde R)
=
\int_0^1
\partial_{\widetilde R}F_{j,x,g}(t\widetilde R)[\widetilde R]\,dt.
\]
仮定 4.2 の一様 bound を使えば
\[
\|F_{j,x,g}(\widetilde R)\|
\le
\int_0^1 C_{\rm tr}\,dt\,\|\widetilde R\|
=
C_{\rm tr}\|\widetilde R\|.
\]
\(\square\)

---

### 仮定 4.4（uniform local convexity）
ある \(\mu>0\) が存在して
\[
D_A^2 s_{j,x}(A;g,\widetilde R)\succeq \mu I
\]
が local window で一様に成り立つとする。

### 命題 4.5（local minimizer control） [C]
仮定 4.1, 4.2, 4.4 の下で、local minimizer \(z_{j,x}(g,\widetilde R)\) は
\[
\boxed{
\|z_{j,x}(g,\widetilde R)\|
\le
\frac{C_{\rm tr}}{\mu}\,\|\widetilde R\|
}
\]
を満たす。

#### 証明
最小点で
\[
D_A s_{j,x}(z;g,\widetilde R)=0.
\]
平均値表示により
\[
0
=
D_A s_{j,x}(0;g,\widetilde R)
+
\left(
\int_0^1 D_A^2 s_{j,x}(tz;g,\widetilde R)\,dt
\right)z.
\]
括弧内の作用素を \(H_z\) と置くと仮定 4.4 から
\[
H_z\succeq \mu I
\]
であり、従って \(\|H_z^{-1}\|\le \mu^{-1}\)。  
よって
\[
\|z\|
\le
\|H_z^{-1}\|\,\|D_A s_{j,x}(0;g,\widetilde R)\|
\le
\mu^{-1} C_{\rm tr}\|\widetilde R\|.
\]
\(\square\)

## 5. connected polymer gluing

### 仮定 5.1（one-step polymer cumulant bound）
各 RG step \(n\) の one-step polymer remainder が
\[
E^{(n)}(\Phi)=\sum_{\Gamma} E^{(n)}_\Gamma(\Phi_\Gamma)
\]
と分解され、
\[
\sup_\Phi \|D_\Phi^2 E^{(n)}_\Gamma(\Phi_\Gamma)\|
\le
A_0 (A_1\varepsilon_n)^{|\Gamma|}
e^{-m_*\operatorname{diam}(\Gamma)}
\]
を満たすとする。

---

### 定理 5.2（polymer norm control） [P]
\(\alpha<m_*\) かつ \(C_{\rm lat}A_1\varepsilon_n<1\) なら
\[
\boxed{
\|E^{(n)}\|_{2,\alpha;\ell}
\le
C_E \varepsilon_n
}
\]
が成り立つ。

#### 証明
polymer norm の定義から、固定 block \(b\) に対して
\[
\sum_{\Gamma\ni b}
e^{\alpha\operatorname{diam}(\Gamma)}
\sup_\Phi\|D_\Phi^2 E^{(n)}_\Gamma(\Phi_\Gamma)\|
\]
を評価すればよい。仮定 5.1 を代入すると
\[
\le
A_0
\sum_{\Gamma\ni b}
(A_1\varepsilon_n)^{|\Gamma|}
e^{-(m_*-\alpha)\operatorname{diam}(\Gamma)}.
\]
\(|\Gamma|=s\) の connected polymer の個数は lattice animal bound
\[
N_s\le C_{\rm lat}^s
\]
で抑えられるから
\[
\le
A_0\sum_{s\ge1}(C_{\rm lat}A_1\varepsilon_n)^s.
\]
幾何級数の収束条件 \(C_{\rm lat}A_1\varepsilon_n<1\) の下で右辺は
\[
\le C_E\varepsilon_n
\]
で抑えられる。 \(\square\)

---

### 系 5.3（exact gluing representation） [P]
step-by-step telescoping を行うと、fixed scale \(\ell\) で exact blocked action は
\[
\boxed{
\mathcal S_{\ell,a,L}^{\rm ex}
=
\mathcal S_{\ell,g_\ell(a),L}^{\rm pr}
+
E_{\ell,a,L}
}
\]
と書け、しかも

\boxed{
\|E_{\ell,a,L}\|_{2,\alpha;\ell}

\]
の形になる。各 step の \(\varepsilon_n\) は scale ratio で
\[
\varepsilon_n\lesssim M^{-2\omega n}
\]
のように減衰するので、前定理を足し上げれば
\[
\|E_{\ell,a,L}\|_{2,\alpha;\ell}
\lesssim
\sum_{n\ge n(a,\ell)} M^{-2\omega n}
\lesssim
\left(\frac a\ell\right)^{2\omega}.
\]
\(\square\)

\(\square\)

## 6. continuum Schwinger functions

### 仮定 6.1（common-scale continuum comparison）
局所 observable \(O\) に対し
\[
\left|
\langle O\rangle_{a,L}
-
\langle O\rangle_{a',L'}
\right|
\le
C_O\left[
\left(\frac a\ell\right)^{2\omega}
+
\left(\frac{a'}{\ell}\right)^{2\omega}
+
e^{-mD/\ell}
\right]
\]
が成り立つとする。

---

### 定理 6.2（projective limit of Schwinger functions） [C]
仮定 6.1 の下で、任意の有限個の局所 gauge-invariant observable \(O_1,\dots,O_n\) に対し
\[
S^{(n)}(O_1,\dots,O_n)
:=
\lim_{a\downarrow0,\ L\to\infty}
\langle O_1\cdots O_n\rangle_{a,L}
\]
が存在する。

#### 証明
固定した \(\ell\) と十分大きい \(D\) に対し、右辺の差は仮定 6.1 により
\[
\lesssim
\left(\frac a\ell\right)^{2\omega}
+
\left(\frac{a'}{\ell}\right)^{2\omega}
+
e^{-mD/\ell}
\]
で抑えられる。  
\(a,a'\downarrow0\) かつ \(L,L'\to\infty\) とすると右辺は 0 に行くから、期待値の net は Cauchy である。完備性により極限が存在する。 \(\square\)

---

### 仮定 6.3（finite-cutoff reflection positivity）
各 cutoff \((a,L)\) で
\[
\langle \Theta F\cdot F\rangle_{a,L}\ge0
\]
が正時間半空間支えの observable \(F\) に対して成り立つとする。

### 命題 6.4（RP passes to the limit） [C]
仮定 6.2, 6.3 の下で continuum Schwinger functions も reflection positivity を満たす。

#### 証明
固定した \(F\) に対し各 cutoff で
\[
\langle \Theta F\cdot F\rangle_{a,L}\ge0.
\]
極限
\[
\lim_{a\downarrow0,\ L\to\infty}
\langle \Theta F\cdot F\rangle_{a,L}
=
\langle \Theta F\cdot F\rangle
\]
が存在するから、非負数列の極限は非負である。 \(\square\)

### 定理 6.5（OS reconstruction） [E]
continuum Schwinger functions が OS axioms を満たせば、vacuum Hilbert 空間 \((\mathcal H,\Omega)\) と非負 self-adjoint Hamiltonian \(H\) が構成される。

#### 証明
標準の Osterwalder--Schrader reconstruction theorem を適用する。 \(\square\)

## 7. mass gap と nontriviality

### 仮定 7.1（dense centered observables）
正時間半空間に支えを持つ centered local observables の可算族 \(\mathfrak D_+\) が存在し、その OS reconstruction による像の線形包の閉包が vacuum 直交補空間
\[
\mathcal H_0:=\Omega^\perp
\]
に稠密であるとする。

### 仮定 7.2（uniform Euclidean time clustering）
ある \(m_{\rm gap}>0\) が存在して、すべての \(O\in\mathfrak D_+\) に対し
\[
\bigl|
\langle O(t)\,O(0)\rangle_c
\bigr|
\le
C_O e^{-m_{\rm gap} t}
\qquad(t\ge0)
\]
が成立する。

---

### 定理 7.3（mass gap from clustering） [C]+[E]
仮定 7.1, 7.2 の下で
\[
\operatorname{spec}(H)\cap(0,m_{\rm gap})=\varnothing
\]
が成り立つ。

#### 証明
centered observable \(O\in\mathfrak D_+\) に対応するベクトルを
\[
\psi_O=[O]\in\mathcal H_0
\]
と書く。OS reconstruction により
\[
\langle O(t)\,O(0)\rangle_c
=
\langle \psi_O,e^{-tH}\psi_O\rangle.
\]
スペクトル定理から正の有限測度 \(\mu_O\) が存在して
\[
\langle \psi_O,e^{-tH}\psi_O\rangle
=
\int_{[0,\infty)} e^{-t\lambda}\,d\mu_O(\lambda)
\]
と書ける。

もし
\[
\mu_O([0,m_{\rm gap}-\varepsilon])>0
\]
なる \(\varepsilon>0\) があれば
\[
\langle \psi_O,e^{-tH}\psi_O\rangle
\ge
\mu_O([0,m_{\rm gap}-\varepsilon])\,e^{-(m_{\rm gap}-\varepsilon)t},
\]
となり、これは
\[
\bigl|
\langle O(t)\,O(0)\rangle_c
\bigr|
\le
C_O e^{-m_{\rm gap} t}
\]
と両立しない。従って
\[
\operatorname{supp}\mu_O\subset [m_{\rm gap},\infty).
\]
\(\mathfrak D_+\) の像は \(\mathcal H_0\) に稠密だから、スペクトル射影
\[
E_H\bigl((0,m_{\rm gap})\bigr)
\]
は \(\mathcal H_0\) 上で 0 である。よって
\[
\operatorname{spec}(H)\cap(0,m_{\rm gap})=\varnothing.
\]
\(\square\)

# 第 VI 部　残る解析義務の reduction theorem

## 9. P4: pair covariance decay の内部化

v85 で principal package の解析的核心として残ったのは、principal measure の指数 mixing である。  
ここでは「何を示せばそれが出るか」を reduction theorem の形で固定する。

### 仮定 9.1（weighted Hessian decomposition）
principal action の Hessian が
\[
H=D+J
\]
と分解され、\(D\) は site-diagonal で
\[
D\succeq \kappa I
\]
を満たすとする。  
さらに weighted operator norm
\[
\|A\|_m:=\sup_b \sum_c e^{m d(b,c)}|A_{bc}|
\]
で
\[
\eta:=\|D^{-1/2} J D^{-1/2}\|_m<1
\]
が成り立つとする。

---

### 定理 9.2（weighted inverse decay） [C]
仮定 9.1 の下で
\[
H^{-1}
=
D^{-1/2}
\left(I+D^{-1/2} J D^{-1/2}\right)^{-1}
D^{-1/2}
\]
は exponentially decaying kernel を持つ。すなわち
\[
|(H^{-1})_{bc}|
\le
C e^{-m d(b,c)}.
\]

#### 証明
\[
\left(I+A\right)^{-1}
=
\sum_{n\ge0}(-A)^n,
\qquad
A:=D^{-1/2} J D^{-1/2},
\]
が \(\|A\|_m<1\) の下で weighted norm 収束する。  
各 \(A^n\) の kernel は weighted norm の submultiplicativity から
\[
|(A^n)_{bc}|\le C\eta^n e^{-m d(b,c)}
\]
で抑えられる。これを足し上げれば
\[
|(I+A)^{-1}_{bc}|\le C' e^{-m d(b,c)}
\]
が従い、左右の \(D^{-1/2}\) を戻せば主張が従う。 \(\square\)

### 定理 9.3（pair covariance decay の reduction theorem） [S]
log-concave principal measure に対して Helffer--Sj\"ostrand / Brascamp--Lieb 型 covariance identity
\[

\le
\sum_{b,c}
\|\partial_b F\|_\infty\,
|(H^{-1})_{bc}|\,
\|\partial_c G\|_\infty
\]
が適用できるとする。  
このとき定理 9.2 から
\[
|\operatorname{Cov}_\mu(F_B,G_C)|
\le
C_{F,G}\,e^{-m\,\operatorname{dist}(B,C)}
\]
が従う。

#### 証明
定理 9.2 で Hessian inverse kernel が指数減衰するので、support が \(B\), \(C\) にある局所 observable について上式の和は
\[
\lesssim
e^{-m\,\operatorname{dist}(B,C)}
\]
で抑えられる。 \(\square\)
